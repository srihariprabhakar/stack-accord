# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature rather than opening a public issue. Include the affected version, reproduction steps, and potential impact.

## Data handling

The Stack Accord CLI scans local files and does not transmit repository contents, findings, or telemetry. JSON and Markdown reports may contain filenames and configuration values inferred from the scanned project; review generated artifacts before sharing them publicly.

Never add real credentials or customer configuration to examples, tests, or bug reports.
